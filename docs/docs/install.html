Install

Download the zip for your app and computer from the home page, then put the plug-in where the app looks for it.

Slippy needs Adobe Illustrator 2026 or Adobe Photoshop 2026. Each app has its own download; install one or both. Downloads are on the home page.

Quit the app first. Plug-ins load when the app starts, so install with it closed, then open it again.

The macOS plug-ins are signed with a Developer ID and notarized by Apple, so macOS opens them without warnings.

Illustrator on macOS

  1. Unzip Slippy-Illustrator-macos.zip. You get Slippy.aip.
  2. Move Slippy.aip into Illustrator's plug-ins folder: /Applications/Adobe Illustrator 2026/Plug-ins. Finder asks for your password the first time; that folder belongs to the system.
  3. Open Illustrator, then Window > Utilities > Slippy. Dock the panel wherever you like.

Illustrator on Windows

  1. Pick the zip for your PC: x64 for most PCs, ARM64 for Snapdragon / ARM laptops. Unzip it to get Slippy.aip.
  2. Copy Slippy.aip into C:\Program Files\Adobe\Adobe Illustrator 2026\Plug-ins (Windows asks for admin permission).
  3. Open Illustrator, then Window > Utilities > Slippy.

Photoshop on macOS

Slippy for Photoshop comes in two parts: Slippy.plugin does the work, and Slippy.ccx is its docked panel.

  1. Unzip Slippy-Photoshop-macos.zip. You get Slippy.plugin and Slippy.ccx.
  2. Make a Slippy folder in Photoshop's plug-ins folder and put Slippy.plugin in it: /Applications/Adobe Photoshop 2026/Plug-ins/Slippy/Slippy.plugin. Finder asks for your password.
  3. Double-click Slippy.ccx. Creative Cloud installs the panel.
  4. Open Photoshop, then Plugins > Slippy. Drag the panel's tab into a dock and Photoshop keeps it there.
No panel? Slippy still works without Slippy.ccx: it shows a floating panel instead, from Window > Slippy.

Photoshop on Windows

  1. Pick the zip for your PC (x64 or ARM64) and unzip it: Slippy.8li and Slippy.ccx.
  2. Copy Slippy.8li into C:\Program Files\Adobe\Adobe Photoshop 2026\Plug-ins.
  3. Double-click Slippy.ccx to install the panel.
  4. Open Photoshop, then Plugins > Slippy.
Windows builds are new. They're built and checked automatically, but haven't had much real use yet. If something's off, open an issue.

Check it's working

Slippy's panel says Listening on 127.0.0.1:7331 (Illustrator) or :7332 (Photoshop). From a terminal:

curl http://127.0.0.1:7331/health    # Illustrator
curl http://127.0.0.1:7332/health    # Photoshop

Each answers {"ok":true,"name":"Slippy",...}. Next: connect an agent.

Updating and removing

To update, quit the app and replace the plug-in file with the new one (and double-click the new .ccx). To remove Slippy, quit the app and delete the plug-in file; for Photoshop's panel, use Plugins > Manage Plugins.
