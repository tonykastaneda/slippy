Connect an agent

One URL is all an agent needs. Copy it from Slippy's panel, add it to your agent, and it can work in the app.

Get Slippy's URL

Click Copy connection in Slippy's panel. It copies a URL like this, with your token at the end:

http://127.0.0.1:7331/mcp/<token>    # Illustrator
http://127.0.0.1:7332/mcp/<token>    # Photoshop

That's an MCP server over streamable HTTP. Any MCP client that supports HTTP servers takes it as is. The token keeps other programs out; it stays the same across launches, so you only add Slippy to an agent once.

Keep the URL private. Anyone with it can drive the app on your computer. The token lives in ~/Library/Application Support/Slippy/token (Photoshop: …/Slippy/Photoshop/token; Windows: %APPDATA%\Slippy). Delete the file to get a new one the next time the app starts.

Claude Code

claude mcp add --transport http slippy-illustrator http://127.0.0.1:7331/mcp/<token>
claude mcp add --transport http slippy-photoshop   http://127.0.0.1:7332/mcp/<token>

Start a new session (or run /mcp) and ask it to do something in Illustrator.

Codex

Add Slippy to ~/.codex/config.toml. mcp-remote bridges Slippy's HTTP server for clients that start servers as commands:

[mcp_servers.slippy-illustrator]
command = "npx"
args = ["-y", "mcp-remote", "http://127.0.0.1:7331/mcp/<token>"]

Cursor

In ~/.cursor/mcp.json (or the project's .cursor/mcp.json):

{
  "mcpServers": {
    "slippy-illustrator": { "url": "http://127.0.0.1:7331/mcp/<token>" },
    "slippy-photoshop": { "url": "http://127.0.0.1:7332/mcp/<token>" }
  }
}

Claude Desktop

In Claude Desktop's claude_desktop_config.json (Settings > Developer > Edit Config):

{
  "mcpServers": {
    "slippy-illustrator": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "http://127.0.0.1:7331/mcp/<token>"]
    }
  }
}

Any other agent

  • Takes an HTTP MCP server (VS Code, Windsurf, Cline, Gemini CLI…): add the URL as the server's URL.
  • Only starts command servers: use npx -y mcp-remote <URL> as the command, as for Codex above.
  • Prefers a header to a token in the URL: use http://127.0.0.1:7331/mcp with Authorization: Bearer <token>.

The terminal in Illustrator's panel

The chevron at the bottom of Illustrator's Slippy panel opens a terminal (macOS). Slippy's URL is already in it, as $SLIPPY_URL, so an agent started there can connect with nothing to paste:

claude mcp add --transport http slippy "$SLIPPY_URL"

The tools agents get

Agents see the everyday commands as their own tools (document_info, art_tree, art_transform, layer_set…), plus four of Slippy's own:

ToolWhat it does
slippy_findSearches every command by words ("gradient", "symbol", "blur") and returns their parameters.
slippy_callRuns any command by name.
slippy_batchRuns several commands as one undo step.
slippy_statusChecks the app is there: versions, open documents.

That keeps the tool list short, which every client can handle. For clients that do well with hundreds of tools, add ?tools=all to the URL to get every command as its own tool.

Scripts and curl

Slippy also speaks plain JSON-RPC at /rpc/<token>, for scripts:

curl -s http://127.0.0.1:7331/rpc/<token> -d '{"jsonrpc":"2.0","id":1,"method":"document.info"}'

Send an array of calls to run them as one undo step.
