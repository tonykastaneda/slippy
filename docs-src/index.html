Slippy is a pair of native plug-ins, one for Illustrator and one for Photoshop, each with an MCP server built in. An agent like Claude Code, Codex or Cursor connects to it and works in your open documents: drawing, editing layers, exporting, and everything else the app can do, one call at a time. Slippy's panel shows each call as it happens, in plain English, with a frog who sleeps, wakes and hops along with the work.

How it works

agent ──MCP──▶ 127.0.0.1:7331  ─▶  Slippy in Illustrator  ─▶  Illustrator's C++ SDK
agent ──MCP──▶ 127.0.0.1:7332  ─▶  Slippy in Photoshop    ─▶  Photoshop's actions

Each plug-in runs a small server on your own computer (it only answers your machine, and only with your token). When an agent calls, Slippy runs the command on the app's main thread, the same way a menu command runs, and sends back the result. Nothing goes through the cloud, and there's nothing else to start: Slippy starts with the app.

The rules Slippy keeps

  • One call, one undo. Every change is one step in Edit > Undo (History in Photoshop), named after what it did. A batch of calls is one step too.
  • Nothing saved by surprise. Closing a document never saves unless the agent asks to.
  • No dialogs. Slippy never pops up a dialog that would freeze the app behind an agent's back.
  • Plain errors. When something can't be done, the agent is told what and why, and you see it in red in the panel.
